# D-Chem &bull; Bahan Ajar Kimia Interaktif SMA

Portal media pembelajaran kimia interaktif berbasis web yang memuat modul digital, laboratorium sains virtual, dokumen LKPD, dan slide presentasi Kurikulum Merdeka (Fase E & Fase F) karya **Dhevira Aptia FIrmanda, S.Pd.**

Mengadopsi sistem desain resmi **Google Stitch**:
- 🍬 **Candy (Tema Terang)**: *Joyful Pop, saturated hot pink, vibrant purple, sky blue, pill-shaped geometries, bouncy hover transitions, tinted shadows*.
- ⚡ **Cyber Candy (Tema Gelap)**: *Luminous Neon Glassmorphism, deep obsidian void, translucent acrylics, glowing candy halos (magenta, electric violet, cyan)*.

🌐 **Dihosting via GitHub Pages / Server Web Mandiri / Berkas Lokal**  
📊 **Database & Sinkronisasi**: Google Sheets API via Google Apps Script (GAS) & Google Drive Folder

---

## 🌟 Fitur Utama
- **Multi-Format Media Pembelajaran**: Mendukung simulasi web HTML interaktif (PhET, simulator kimia), dokumen modul/LKPD PDF, slide presentasi Google Slides/PPT, dan video edukasi.
- **In-App Document & Slide Viewer**: Membaca LKPD PDF dan slide presentasi langsung di dalam web tanpa harus keluar aplikasi atau mengunduh berkas.
- **Utilitas Kimia Terpadu**: Kalkulator Massa Molar (Mr) otomatis, Penyetara Reaksi Kimia (Equation Balancer), dan Kamus Istilah Kimia (Glossary) SMA.
- **Pencarian Cepat & Filter Multi-Format**: Filter format (Semua, HTML Interaktif, Modul PDF, Slide PPT, Favorit) dan fase jenjang (Kelas 10, Kelas 11, Kelas 12).
- **Mode Guru Terproteksi**:
  - Kata Sandi Akses Guru: guru08123
  - Tambah, edit, dan hapus bahan ajar
  - Auto-sync dengan folder Google Drive dan Google Sheets
- **Progressive Web App (PWA) & Akses Offline**: PWA berstandar modern dengan service worker offline cache (sw.js) dan ikon resmi Google Stitch D-Chem (icon.svg).
